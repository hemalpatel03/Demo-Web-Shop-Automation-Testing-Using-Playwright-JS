# Demo-Web-Shop-Automation-Testing-Using-Playwright-JS
This repository contains end-to-end automation testing for the Demo Web Shop application developed using Playwright with JavaScript.
The main objective of this project is to automate critical user flows of the Demo Web Shop website and ensure the functionality, stability, and reliability of the application across different scenarios.

🔧 Tech Stack & Tools Used

Language (LAN): JavaScript

Automation Tool: Playwright

Test Runner: Playwright Test Runner

Browser Support: Chromium, Firefox, WebKit

Framework Type: End-to-End Automation Framework

IDE Used: Visual Studio Code

Version Control: Git & GitHub

🧪 What is Covered in This Project?

The following test scenarios are automated using Playwright:

✅ User Registration

✅ User Login & Logout

✅ Product Search

✅ Add to Cart

✅ Update Cart Quantity

✅ Checkout Flow

✅ Page Navigation & UI Validation

✅ Positive & Negative Test Scenarios

Each test is written in a structured and readable format using Playwright’s built-in test runner and assertion library.

🚀 Key Features of the Framework

Modular and reusable test structure

Uses Playwright test runner for execution

Automatic waits handled by Playwright

Supports parallel test execution

Screenshots, videos, and traces on failure

Cross-browser testing support

Easy to maintain and scalable

▶️ How to Run the Tests

Clone the repository

Install dependencies using npm install

Run tests using:

npx playwright test


View HTML report using:

npx playwright show-report
