# 🛒 Demo Web Shop Automation Testing Using Playwright (JavaScript)

## 📌 Project Overview
This project contains **end-to-end automation testing** for the **Demo Web Shop** application using **Playwright with JavaScript**.  
The goal of this project is to validate critical user flows and ensure the application works correctly across different browsers.

This framework is built using **Playwright Test Runner**, which provides fast execution, auto-wait handling, and reliable cross-browser testing.

---

## 🧰 Tech Stack & Tools

- **Language (LAN):** JavaScript  
- **Automation Tool:** Playwright  
- **Test Runner:** Playwright Test Runner  
- **Framework Type:** End-to-End Automation  
- **IDE:** Visual Studio Code  
- **Version Control:** Git & GitHub  
- **Browsers Supported:** Chromium, Firefox, WebKit  

---

## 🌐 Application Under Test
- **Website:** https://demowebshop.tricentis.com/

---

## 🧪 Test Scenarios Covered

- User Registration  
- User Login & Logout  
- Product Search  
- Add Product to Cart  
- Update Cart Quantity  
- Checkout Process  
- Navigation and UI Validation  
- Positive and Negative Test Cases  

---

## ✨ Key Features

- Modular and reusable test cases  
- Built-in Playwright assertions  
- Automatic waits (no hard waits required)  
- Parallel test execution  
- Cross-browser testing support  
- Screenshot, video, and trace capture on failure  
- Easy to maintain and scalable framework
